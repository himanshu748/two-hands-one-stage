# Rehearsal handoff follow-up

Verified November 5, 2026, with Node **22.14.0**, pnpm **10.34.9** and Chromium through the existing Playwright configuration.

## What changed

The existing landing page, brief composer and studio already support interactive scene exploration. This increment closes the gap after cue playback: the performer can prepare a revision-linked message from **Record**, then copy it into the linked Mattermost channel.

- The performer chooses a staging repair request, a difficult rehearsal outcome, or a successful outcome. The form explains that recording difficulty alone does not request a repair.
- The text starts empty. Preparing a message requires an explicit confirmation that the person performed the named approved revision with actual props. Their original text, including newlines and Unicode, is preserved.
- Commands use the API's existing `observe <revision> <text>` and `outcome <revision> difficulty|success <text>` grammar, addressed to `@two-hands-stage`.
- Preparation and copying do not send a message, approve anything, or create rehearsal evidence. The authenticated Mattermost-to-Switch ingestion path remains responsible for all those decisions.
- A disconnected notice distinguishes a local draft from delivery. Success is unavailable while a repair or approval hold remains. Revision/digest/hold changes clear the prepared message and confirmation; revoked approval or API failure removes the composer.
- Clipboard pending, success and denial have visible text. On denial, the exact command is selected for manual copying. A delayed clipboard response cannot label an edited report as copied.
- **Escape** pauses cues even when a playback button has focus. After pausing or completing cues, **Describe rehearsal** opens Record and focuses its heading, on desktop and mobile. Finishing the timer explicitly says no rehearsal was recorded.
- The message appears with a brief 180ms reveal, disabled under reduced motion. Controls use native keyboard interaction, visible focus and 44px minimum action targets.

The draft lives only in component memory; leaving Record or refreshing discards it. Already copied clipboard text cannot be revoked by the web page. The API still validates any eventual Switch instruction against the current revision and approval state.
